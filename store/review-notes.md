[English]
1. Screen recording: Attached to our reply to the Guideline 2.1 message and to the App Review Information attachments. Captured on a physical iPhone 16 running iOS 26.7, starting from launching the app from the Home Screen. It shows: Home (Musubi Coach, Lv. 1, next step) > Settings: select Mario as my character > Record: Mario vs Link, Win, Save > Home > Improve: today's practice (10/30/60 min), roadmap, Mario's character menu, glossary, sources > Matchups: "マリオの相性表を開く（シラツキ理論）" opens ssbu-shiratsuki-theory.net in the browser. No account, login, user-generated content shared with others, paid content, or in-app purchases.

2. Purpose / audience: A free personal notebook for fighting game players, especially Super Smash Bros. Ultimate beginners. Players record matches and loss reasons; the app shows weak matchups and suggests what to practice next. The 上達 (Improve) tab adds a 4-stage practice roadmap, a beginner menu for each character, a practice timer, a glossary, and XP/levels. UI is Japanese.

3. How to use: No login or sample files needed. Settings: pick your characters. Record: enter a match and loss reasons, tap 記録する. Home: guide character, level, focus areas, drills, win-rate graph. Improve: choose 10/30/60 min, Start, then "今日完了として記録"; check roadmap/character items to earn XP. Matchups: matchup table, marks and memos; the reference button opens a public statistics site in the browser. Settings > "このアプリについて": disclaimer and privacy policy. Birthday screen: on October 15 (device date) it appears at every launch until the user closes it; after that it does not appear again that year. To see it, set the device date to October 15, force-quit the app, and launch it again.

4. External services: None. Fully offline, no server communication, no analytics/ads/AI/payments/auth, no data collected or transmitted. Built with Capacitor (runs locally). Font bundled. Links (statistics site, privacy policy on GitHub, reference guide pages in the Improve tab) open in the browser only when tapped.

5. Regional differences: None. Works identically in all regions. UI is Japanese.

6. Third-party material: Game character names are used as text only, for identification; no game images, logos, or sounds. Unofficial fan tool, not affiliated with Nintendo; stated in the description and in Settings > "このアプリについて". Matchup references are links to a public statistics site only; the data itself is not bundled. Practice tips are written in our own words with links to referenced guide pages. Heading font: DotGothic16 (SIL OFL 1.1, license bundled). All pixel art, including the guide character むすびコーチ (Musubi Coach), is original.

Build 1.0 (4) adds (vs. build 3): the Improve tab (roadmap, character beginner menus, practice timer, glossary, levels), the original pixel-art guide character, and the birthday screen. Tested on a physical iPhone 16 (iOS 26.7).
