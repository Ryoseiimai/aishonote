[English]
1. Screen recording: Attached to our reply to the Guideline 2.1 message (physical iPhone 16, latest iOS, starting from app launch). No account, login, user-generated content shared with others, paid content, or in-app purchases.

2. Purpose / audience: A free personal notebook for fighting game players, especially Super Smash Bros. Ultimate beginners. Players record matches and loss reasons; the app shows weak matchups and suggests what to practice next. The 上達 (Improve) tab adds a 4-stage practice roadmap, a beginner menu for each character, a practice timer, and XP/levels. UI is Japanese.

3. How to use: No login or sample files needed. Settings: pick your characters. Record: enter a match and loss reasons. Home: focus areas, drills, win-rate graph. Improve: choose 10/30/60 min, Start, then "今日完了として記録"; check roadmap/character items to earn XP. Matchups: matchup table, marks and memos; the reference link opens a public statistics site in Safari. Settings > "このアプリについて": disclaimer and privacy policy. Birthday card: shown once on October 15 (device date) at launch; set the device date to Oct 15 and relaunch to see it.

4. External services: None. Fully offline, no server communication, no analytics/ads/AI/payments/auth, no data collected or transmitted. Built with Capacitor (runs locally). Font bundled. Links (statistics site, privacy policy on GitHub, reference guide pages) open in Safari only when tapped.

5. Regional differences: None. Works identically in all regions. UI is Japanese.

6. Third-party material: Game character names are used as text only, for identification; no game images, logos, or sounds. Unofficial fan tool, not affiliated with Nintendo; stated in the description and in Settings > "このアプリについて". Matchup references are links to a public statistics site only; the data itself is not bundled. Practice tips are written in our own words with links to referenced guide pages. Heading font: DotGothic16 (SIL OFL 1.1, license bundled). All pixel art, including the guide character むすびコーチ (Musubi Coach), is original.

Build 1.0 (4) adds (vs. build 3): the Improve tab (roadmap, character beginner menus, practice timer, levels), the original pixel-art guide character, and the birthday screen.
