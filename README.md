# 相性ノート

対戦ゲームの相手キャラ相性と負け理由を記録し、「次に何を練習すべきか」を自動で提示するツールです。
大乱闘スマッシュブラザーズ SPECIAL向けのプリセット（全ファイター・専用練習メニュー）を同梱しています
（任天堂非公式のファン製ツール）。プリセット以外のゲームも「カスタムゲーム」として自由に追加できます。

## 使い方（3行）

1. 「設定」タブでゲーム（初期状態は大乱闘スマッシュブラザーズ SPECIALのプリセット）と自分の使用キャラを選ぶ。
2. 対戦が終わるたびに「記録」タブで日付・自キャラ・相手キャラ・勝敗・負けた理由を10秒で入力する。
3. 「ホーム」タブに今週の課題と練習メニュー、苦手な相性、勝率グラフが自動で表示される。

データはすべてブラウザの localStorage にのみ保存されます。サーバーへの送信やログインは一切ありません。

## ローカルで動かす

外部依存もビルドも不要です。リポジトリ直下で以下を実行してください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開くと動作します。

## 相性の目安を更新する

Node.js 22以降で `node scripts/fetch-matchups.mjs` を実行すると、
[シラツキ理論](https://ssbu-shiratsuki-theory.net/chara_link.html)のキャラ一覧と各相性ページを
連絡先入りのUser-Agent付き・直列・リクエスト間3秒で取得し、`js/presets/matchup-reference.js` を上書きします。
ブラウザでは同梱データのみを表示し、外部サイトへの自動アクセスは行いません。
取得スクリプトはレート戦の期が更新されたときだけ手動で実行する。CIや定期実行には組み込まない。

Web版は同梱データ（相性表の抜粋）を表示します。iOSアプリ版は出典の運営者の許諾が取れるまで同梱データを表示せず、
出典の相性表ページへのリンク（タップしたときだけSafariで開く）だけを出します（`js/reference-display.js` の
`EMBED_REFERENCE_ON_NATIVE`）。

出典の最新掲載はスマメイト21期です（現在のレート戦期間とは限りません）。公開されているのは、
レート等を調整した1先の**勝率帯と相性順**で、個別の勝率や対戦数ではありません。
勝率帯内も含めて掲載順の両端から各6件を採用し、数値の推定や理由の生成は行いません。
自己対戦と「不明」を除き、対戦数は出典の「一定試合数以上」という掲載条件を使います。
件数・閾値が非公開のため、追加の少数試合フィルタや `n=` の表示はできません。

出典の81ページを86ファイターへ正規化しています。サムス／ダークサムス、ピーチ／デイジー、
マルス／ルキナ、ピット／ブラックピット、シモン／リヒターは出典が統合しているため共通データとし、
自キャラ・相手キャラそれぞれの合算対象を注記しています。同じ統合枠との対戦も除きます。
未対応slugや取得失敗は警告し、取得できた分だけ生成して最後に取得数と欠落キャラを表示します。
全件失敗した場合は既存ファイルを保持します。

## 技術的な特徴

- 依存ライブラリ・ビルドツール・外部CDN・外部フォント・アクセス解析ツールを一切使用しない、素の
  HTML/CSS/ES Modulesのみで構成されています。
- `innerHTML` を一切使わず、DOM APIのみで画面を組み立てています（`js/dom.js`）。
- データモデルはゲーム非依存です。`state.games` に複数ゲームを保持し、対戦ログ・相性表はゲームIDで
  分けて管理します。プリセット（大乱闘スマッシュブラザーズ SPECIAL、`js/presets/ssbu.js`）に加えて、
  設定画面から「カスタムゲーム」「カスタムキャラ」を自由に追加できます。
- 練習メニューはプリセット専用（`js/presets/ssbu-drills.js`）とカスタムゲーム向けの汎用版
  （`js/drills-generic.js`）を用意しています。
- JSONインポート時はスキーマ検証（型・必須キー・上限件数・文字数上限・許可キー以外の破棄）を行い、
  検証に失敗した場合は既存データを一切上書きしません。
- `node --test` によるユニットテスト（集計ロジック・スキーマ検証）と、GitHub Actionsでの静的チェック
  （`innerHTML`代入・`eval`・`document.write`・外部URLの禁止パターン検出）をCIで実行しています。

## 非公式であることについて

同梱している大乱闘スマッシュブラザーズ SPECIALプリセットは任天堂非公式のファン製コンテンツです。
キャラクター名はテキストのみを使用しており、任天堂の公式画像・音源・ロゴは一切同梱していません。
任天堂株式会社および関連企業とは無関係です。

## プライバシーポリシー

- 記録（対戦ログ・相性表・メモ・設定）はお使いの端末（ブラウザの localStorage／iOSアプリ内の保存領域）の中だけに保存され、外部に送信されません。
- 氏名・メールアドレス・位置情報・利用状況などの個人情報は一切収集しません。アクセス解析・広告・トラッキングもありません。
- アプリが外部サーバーと通信することはありません。相性表の出典などの外部リンクは、タップしたときだけブラウザ（iOSではSafari）で開きます。
- データを第三者へ提供・共有することはありません。
- お問い合わせ: [GitHub Issues](https://github.com/Ryoseiimai/aishonote/issues)

詳細は [`docs/privacy.md`](docs/privacy.md) を参照してください。
