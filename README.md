# 相性ノート

対戦ゲームの相手キャラ相性と負け理由を記録し、「次に何を練習すべきか」を自動で提示するツールです。
大乱闘スマッシュブラザーズ SPECIAL向けのプリセット（全ファイター・専用練習メニュー）を同梱しています
（任天堂非公式のファン製ツール）。プリセット以外のゲームも「カスタムゲーム」として自由に追加できます。

## 使い方（3行）

1. 「設定」タブでゲーム（初期状態は大乱闘スマッシュブラザーズ SPECIALのプリセット）と自分の使用キャラを選ぶ。
2. 対戦が終わるたびに「記録」タブで日付・自キャラ・相手キャラ・勝敗・負けた理由を10秒で入力する。
3. 「ホーム」タブに今週の課題と練習メニュー、苦手な相性、勝率グラフが自動で表示される。

データはすべてブラウザの localStorage にのみ保存されます。サーバーへの送信やログインは一切ありません。

## ローカルで動かす

外部依存もビルドも不要です。リポジトリ直下で以下を実行してください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開くと動作します。

## 技術的な特徴

- 依存ライブラリ・ビルドツール・外部CDN・外部フォント・アクセス解析ツールを一切使用しない、素の
  HTML/CSS/ES Modulesのみで構成されています。
- `innerHTML` を一切使わず、DOM APIのみで画面を組み立てています（`js/dom.js`）。
- データモデルはゲーム非依存です。`state.games` に複数ゲームを保持し、対戦ログ・相性表はゲームIDで
  分けて管理します。プリセット（大乱闘スマッシュブラザーズ SPECIAL、`js/presets/ssbu.js`）に加えて、
  設定画面から「カスタムゲーム」「カスタムキャラ」を自由に追加できます。
- 練習メニューはプリセット専用（`js/presets/ssbu-drills.js`）とカスタムゲーム向けの汎用版
  （`js/drills-generic.js`）を用意しています。
- JSONインポート時はスキーマ検証（型・必須キー・上限件数・文字数上限・許可キー以外の破棄）を行い、
  検証に失敗した場合は既存データを一切上書きしません。
- `node --test` によるユニットテスト（集計ロジック・スキーマ検証）と、GitHub Actionsでの静的チェック
  （`innerHTML`代入・`eval`・`document.write`・外部URLの禁止パターン検出）をCIで実行しています。

## 非公式であることについて

同梱している大乱闘スマッシュブラザーズ SPECIALプリセットは任天堂非公式のファン製コンテンツです。
キャラクター名はテキストのみを使用しており、任天堂の公式画像・音源・ロゴは一切同梱していません。
任天堂株式会社および関連企業とは無関係です。
